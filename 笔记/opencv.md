##### 视频操作
首先要创建一个VideoCapture类型的对象
```C++
VideoCapture  cap（0）；
```
参数为0代表使用默认摄像头，如果要对现有的视频需传入视频路径
然首进入循环：
```
Mat frame;

while(true)
{
	cap>>frame;
	if(frame.empty())
	{
		break;
	};
};
```
接下来的所有操作对frame进行

##### Point2f类型

##### pnp
位姿解算，一个世界点经过旋转和平移会变换到相机坐标系，再经过相机内参变换到图像坐标系，pnp就是求解旋转向量和平移向量的过程，opencv中封装好了pnp算法
```C++
solvePnP（
	objectPoints，  //世界坐标点
	imagePoints,    //图像坐标点
	cameraMatrix,   //相机内参
	distCoeffs,     //相机畸变
	rvec,    //输出：//旋转向量
	tvec,           //平移向量
	false,          //是否使用初始rvec、tvec进行迭代
	SOLVEPNP_IPPE   //算法
	）
	

```

一般来说，要求世界坐标点数量大于等于3，但是数量为三时会有多个解，所以一般都会多几个点来验证，并且点不能共面，但是IPPE这个算法针对的是共面的情况，这时的点可以共面，而且装甲板上的点也是共面的，可以使用这种算法
但是pnp得出的都是向量，没办法直接求欧拉角，这时需要把向量转为矩阵

##### cv：：Rodrigues（）
将旋转矩阵和旋转向量互相转换，在pnp后，得出的旋转向量可以通过这个函数转为矩阵，以便于算欧拉角:

```C++
auto pitch = -std::asin(r23);

auto yaw = std::atan2(r13,r33);

auto roll = std::atan2(r21,r22);
```
