### 编辑器和编译器的区别
###### 编辑器：
只能编辑代码，类似于文本编辑器，编辑的代码是给人看的
###### 编译器：
将代码编译成可执行文件，让人能看的懂的代码变成计算机可以执行的二进制文件

例如vscode就是一个支持多种文件格式的文本编辑器，本身没有编译的功能，通常使用g++等编辑其来进行编译

### apt（类似于应用商店）
```
sudo apt update //更新apt本身

sudo apt upgrate //更新电脑上的软件
```
