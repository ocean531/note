
## can
#### socket can是什么
socketcan把CAN总线包装成了一种linux socket可以操作的网络接口，通过句柄对文件进行读写IO操作
#### canframe
socketcan中基础的结构体，来自<linux/can.h>
```cpp
#include<linux/can.h>

struct can_frame
```
frame.can_id , 就是CANID
frame.can_dlc，表示该can帧中有8个数据字节
frame.data[]，表示数据

#### 创建虚拟can
```bash
sudo modprobe vcan

sudo ip link add dev vcan0 type vcan
sudo ip link set up vcan0
```



## 使用socat创建虚拟串口
```
socat -d -d pty,raw,echo=0 pty,raw,echo=0
```
使用这个指令，可以创建两个相连的虚拟串口，可以通过程序来互相发送接收

## 串口
### serial库
需要先实例化一个serial对象，然后设置串口和波特率，打开串口，发送数据
```cpp
int main(){

serial::Serial serial;//实例化一个串口对象

serial.setPort("/dev/ttyACM0"); //设置串口名称

serial.setBaudrate(115200);//设置波特率

try{
serial.open();//打开串口

while (true)

{
	serial.write(reinterpret_cast<uint8_t*>(&vgd),sizeof(vgd));
}

}catch (const std::exception & e){

std::cerr << e.what() << std::endl;

}


return 0;

}
```

## 为USB串口固定一个设备名
串口的命名通常是按照设备上电的顺序来决定，也就是说每次连接设备或者重新开机时的串口名都不同，所以我们可以给串口绑定一个固定名称
首先，查看设备的信息
```Bash
lsusb
```
会显示各个端口的信息
我们需要的是XXXX：XXXX，也就是VID和PID
在/etc/udev/rules.d 下写一个随意名称的.rules文件
写入
```
SUBSYSTEM==“usb”，//设备所属子系统
KERNEL=="ttyUSB*", //设备当前的内核名称   二者通常互相搭配使用
ATTRS{idVendor}=="10c4",ATTRS{idProduct}=="ea60", 
MODE:="0777", 
SYMLINK+="rplidar"//绑定的名称
```
再
```
ls /dev/
```
就会显示定义的固定名称，而且也会显示本来的名称，操作这两个名称都是一样的，
